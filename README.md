# QnAI

> No student left behind.

QnAI is a real-time classroom companion that helps professors stay in sync with their students. Students can anonymously flag confusion and get instant AI-powered help, while professors see a clean, compressed signal of where the class is struggling — without being flooded with raw queries.

---

## How It Works

**For Students**
1. See the current lecture topic set by the professor
2. Hit **"I'm Lost"** and type your question
3. Get an instant AI explanation grounded in the topic
4. Still confused? Escalate anonymously to the professor

**For Professors**
1. Set the current lecture topic
2. Monitor a live confusion dashboard
3. See compressed 3-4 word confusion tags (e.g. *"gravity force confusion"*)
4. Get alerted when multiple students are stuck

---

## Tech Stack

- **React + Vite** — Frontend
- **Tailwind CSS** — Styling
- **Google Gemini API** — AI explanations + query compression

---

## Getting Started

```bash
# Clone the repo
git clone https://github.com/Abh1shekPramanik/QnAI.git
cd QnAI

# Install dependencies
npm install

# Add your Gemini API key
echo "VITE_GEMINI_API_KEY=your_key_here" > .env

# Run the app
npm run dev
```
